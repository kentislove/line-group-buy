1. 登入

網址：https://kentislove.github.io/line-group-buy/admin.html

  1. 輸入密碼後按「登入」
  2. 瀏覽器會記住，下次打開就不用再輸入
  3. 要換人用或退出 → 右上角「登出」

2. 每週固定流程

每週一開團，一週可能做這些動作：

週一（開新團）
1️⃣ 📅 週期與排班 → 新增下週的週期（如果還沒有）
2️⃣ 勾選本週要上架的商家和攤位
3️⃣ 把網址 https://kentislove.github.io/line-group-buy/ 丟到 LINE 群組
週間（有客人下單）
• 🧾 訂單 看最新訂單
• 客人要改訂單 → 進訂單卡片編輯或刪掉重下
週日 17:00 後（結單）
• 📊 報表 → 按「列印 / 存 PDF」印出訂購明細
• 或按「匯出 Excel」下載 CSV 整理

3. 管理代購商家

進 🛒 代購商家 分頁。這裡的清單是「永久清單」，新增一次就一直在。要排哪一週有出現，去「週期與排班」勾選。

新增商家

  1. 按「⚡ 快速新增商家」
  2. 只要填 5 樣：
    • 商家名稱
    • 收代購費：下拉「收」或「不收」
    • 代購費：填數字。不收填 0。不可留白
    • 費用模式：下拉「定額（整單加 $X）」或「百分比（按小計 %）」
    • 圖片：按「📷 選擇照片」上傳
  3. 按「儲存」
欄位比較多的「完整新增（進階）」保留原本所有欄位，一般用快速新增就好。

編輯 / 刪除商家

  • 每張商家卡片右下有「編輯」「刪除」
  • 刪除會問一次確認，按確定才真的刪

4. 管理現場攤位

進 🏪 現場攤位 分頁。攤位的意思是「老闆本人週一來擺攤直接賣」，和代購商家（團購主代訂、取貨日分發）不同。

流程跟代購商家一樣：

  1. 按「⚡ 快速新增攤位」→ 填攤位名稱、上傳圖片 → 儲存
  2. 要編輯 / 刪除 → 卡片右下按鈕

5. 管理商品

商品是「掛在商家或攤位底下」的。要新增商品，先進那個商家的頁面：

  1. 進 🛒 代購商家（或 🏪 現場攤位）
  2. 找到要新增商品的那家 → 按「📦 管理商品」
  3. 按「⚡ 快速新增商品」
  4. 填 4 樣：品名、單價、單位（例：個、份、盒）、圖片
  5. 按「儲存」

看完商品管理，按「← 回代購商家清單」回上一層。

6. 每週排班勾選

進 📅 週期與排班 分頁。這一步決定前台「這週會出現哪些商家、哪些攤位」。

新增一個週期

  1. 按「➕ 新增週期」
  2. 填：
    • 週期編號：留空會自動用「下個週一日期」產生，例如 W20261207
    • 取貨起日：那週的週一
    • 下單截止：前一週日的 17:00
    • 狀態：下拉「開放中」

勾選該週有哪些商家 / 攤位

  1. 在週期卡片按「設定排班」
  2. 兩個清單出現：
    • 🛒 本週代購商家：勾起來的這週就會出現
    • 🏪 本週擺攤攤位：勾起來的這週才會出現
  3. 按「💾 儲存這週排班」
沒勾的商家 / 攤位，就算有商品也不會出現在前台。

7. 查看訂單

進 🧾 訂單 分頁。所有客人下的單依下單時間，新的在上面。

每張訂單卡片會顯示：

  • 客人姓名、電話（如果有填）
  • 下單時間、對應週期
  • 買了哪些商品（連商家名字也會顯示）
  • 備註（如果有）
  • 總計金額

刪除訂單

每張卡右下有「整筆刪除」。按下去會問確認，按確定後整張訂單（所有商品）一次刪完。

刪除不能救回。如果客人要改訂單，建議請客人重新下一次，然後刪舊的。

8. 報表、列印、匯出

進 📊 報表 分頁。會看到本週每個客人買了什麼、各自總計多少、本週總營收。

🖨️ 列印 / 存 PDF

  1. 按「🖨️ 列印 / 存 PDF」
  2. 會跳出新頁面（乾淨、黑白印友善）
  3. 電腦：會自動彈列印對話框。想印紙本就選印表機，想存 PDF 選「另存為 PDF」
  4. 手機：按新頁面右上角「🖨️ 列印 / 存 PDF」按鈕 → 用 AirPrint 或分享給印表機 / 儲存為 PDF

📊 匯出 Excel

  1. 按「📊 匯出 Excel」
  2. 下載一個 CSV 檔，檔名如 團購報表_W20261130.csv
  3. 雙擊用 Excel 打開
  4. 電話欄位會保留前面的 0（不會被吃掉）
CSV 可以直接丟給店家或會計整理。

9. 常見問題

Q1：前台進去看不到任何商家？
去「週期與排班」確認：有沒有建立本週的週期？本週的商家和攤位有沒有勾起來？
Q2：新增商家時「代購費」欄位可以留空嗎？
不行。不收代購費請填 0。
Q3：代購費想收 10% 要怎麼填？
「費用模式」選「百分比」，「代購費」欄位填 10（代表 10%）。
Q4：客人說下單後沒跳出分享到 LINE？
下單成功後會跳一個白色彈窗，上面有綠色「📲 分享到 LINE」大按鈕。沒跳出來請確認瀏覽器沒擋彈窗。
Q5：報表列印在手機上按沒反應？
在新開的列印頁面右上角有「🖨️ 列印 / 存 PDF」綠色按鈕，按那個才會真的印。直接按瀏覽器的列印在手機上有時候不會動。
Q6：圖片上傳失敗？
圖片不能超過 5MB。手機拍的照片通常都不會超過。如果真的太大，用其他 app 先壓縮。
Q7：訂單想要補打電話怎麼辦？
進訂單卡片按「編輯」→ 改電話欄位 → 儲存。
Q8：下單截止時間要改？
去「週期與排班」→ 編輯那個週期 → 改「下單截止」時間。
